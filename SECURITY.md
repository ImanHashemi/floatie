# Reporting a vulnerability

A verified private reporting route is **not currently available**. Do not put
vulnerability details, exploit instructions, credentials or private workspace
data in public issues, pull requests or discussions.

The intended route is GitHub private vulnerability reporting: on this
repository's **Security** tab, select **Report a vulnerability**, if available.
Its availability must be verified before publication. A missing button does not
mean a report has been received or that another private channel exists. No
alternative contact address has been designated. Publication remains blocked
until the maintainer enables and verifies that route or supplies a working
private alternative.

Once a private route is available, include the affected revision, host and Lima
versions, a minimal synthetic reproduction, expected and observed behavior, and
the impact. Remove tokens, personal data and private repository content. No
response-time commitment or supported-version policy is established yet.

Read the [security model](docs/guides/security.md) for mount, credential, network
and UI boundaries. The VM is not a containment environment for hostile code.
