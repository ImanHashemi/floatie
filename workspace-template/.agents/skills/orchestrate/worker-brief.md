# Worker brief

Keep the filled brief and result private under `~/work/.floatie-local/`.

- **Assignment:** concrete outcome and acceptance criteria.
- **Scope:** worker name, exact repository set, owned files, base/branch and
  excluded work. Inspect existing status and handoff before changing anything.
- **Context:** repository instructions, authoritative decisions, interfaces and
  prerequisite results. Missing decisions remain open questions.
- **Execution:** use the assigned guest worktrees; preserve existing changes.
  One primary agent owns the worker. Coordinate shared files and Git index use.
- **Verification:** commands and actual scenarios; record failure reproduction,
  passing evidence and any missing environment. Never substitute main's results.
- **Authority:** routine work and tool approvals within this assignment only.
  Human review/merge and production/external actions retain their explicit gates.
- **Delivery:** changed filenames, signed commit when authorized, verification
  evidence, concerns and remaining work. No push or cleanup unless authorized.
- **Handoff:** current branch/status, running sessions, decisions, blockers and
  next step. Preserve dirty/untracked files and unpushed work; never hide them.
